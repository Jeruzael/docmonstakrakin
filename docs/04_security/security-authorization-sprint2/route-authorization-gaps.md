# Sprint 2 authorization gap register

**Evidence revision:** `f35fa7bcd9fb00942c1bba76741a22a5cc7c80b8`. **Status:** source-verified current gaps and proposed remediation; no authorization implementation.

All 69 actual registrations were independently extracted from the five registration files and compared with `API_ROUTE_POLICIES`: **45 LEGACY_LOCAL_UNSCOPED; 14 blocked (7 secret/AI status, 6 Git, 1 dispatch); 7 SPECIALIZED_REVIEWER; 3 REVIEWER_SESSION**. Terminal WorkItem status gates are an additional conditional protection inside one legacy registration. They are not a separate route.

We can distinguish selecting the URL's project dictionary from proving entitlement to that project. The first exists; general membership does not. A native local caller can supply accepted Host headers without becoming a human. Browser-origin containment remains useful, but is not the missing identity control.

## Evidence and limits

The [15-case actual-server characterization](evidence/characterization.log) used the real `server.ts` with synthetic state, a synthetic roster and isolated Git/vault/document fixtures. **15/15 expected observations reproduced; this is not a security-pass claim.** Every registration was source-reviewed; not every endpoint was dynamically exercised. No real member-A/member-B relationship exists to test yet. Future expiry, policy revocation and delegation tests below are proposed, not executed. The first probe omitted the diff endpoint's required base hash (422); supplying its actual synthetic document hash corrected the request without weakening its 200 assertion.

The distributable [probe source](evidence/probe-authorization-gaps.ts.txt) is evidence, not application code. To reproduce, create a disposable clone at the evidence revision, run `npm ci`, copy it to `scripts/probeAuthorizationGaps.ts`, set `DMK_SPRINT2_PROBE_RESULT_PATH` to a disposable output file, then run `node --import ./node_modules/tsx/dist/loader.mjs scripts/probeAuthorizationGaps.ts`. Never run preparation/probes against operator state. The probe creates and deletes its own OS-temp fixture and does not call release signoff or write canonical WBS.

## Aliases, side effects and coverage obligations

Express GET-to-HEAD, case-insensitive paths and optional trailing slash must share policy. Existing ambiguous encoded separators, forwarding claims and unknown API registrations fail closed; retain these controls. A POST described as read-only by its handler may still enter the snapshot middleware (compiler and package verification do). Document diff/validate bypass it only for the exact current classifier representation; alternate case/trailing-slash forms can be treated as mutating. Future authorization must therefore precede the persistence interceptor for every representation, not merely precede the business mutation.

Apply resource checks to route IDs, package destination IDs and every linked artifact ID. Resolve identity from the server session/delegation, never from actor, project, owner, role or agent persona fields. Recheck current permission revision at the coordinated commit boundary; no file/journal/snapshot write or successful business audit follows denial. Rejected-request security telemetry belongs to a separate bounded sink and must not corrupt project evidence.

Human/machine delegation and secret/Git re-enablement remain blocked. Loopback HTTP does not isolate mutually hostile local applications or an attacker with the operator's filesystem/process rights. Browser transport and bootstrap/recovery decisions require human review before activation.
