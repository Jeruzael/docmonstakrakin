4. Prohibited Fields & Data
The bootstrap manifest must not contain:
Passwords or passphrases;
SecretStore master keys or encryption material;
Authentication tokens, bearer tokens, or session keys;
API keys (Gemini or third-party);
Machine tokens (.machine_token);
Reviewer password verifiers or credential hashes;
Private keys or certificates.
Structural Sensitive-Key Scanner:
A recursive key scanner rejects any object property matching /password/i, /secret/i, /apikey/i, /api_key/i, /token/i, /privatekey/i, /machinetoken/i, /credential/i, /verifier/i, /passphrase/i, or /auth_tag/i.
Security Invariant: Error messages report only the offending property path; secret-like values are never printed or exposed.
